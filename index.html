Computer Networks · Project 28

Proxy & Content Filtering System using TCP + SDN

  • Every client request passes through our concurrent TCP proxy and is checked against ordered filter rules: allowed requests reach the server, blocked ones get 403.
  • Clients that keep breaking the rules are reported to the SDN controller, which drops them right at the switch. Rules can be changed live.
